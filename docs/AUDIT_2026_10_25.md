## Prüfung und Reproduktion

```sh
python3 -m unittest discover -s scripts -p 'test_*.py'
python3 scripts/render_todo.py
python3 scripts/project_state.py
python3 scripts/render_todo.py --check
python3 scripts/project_state.py --check
git diff --check
```

Tests decken falschen Abschluss, Unteraufgaben, unbekannte/doppelte IDs,
Zyklen, Blockaden, Abweichungen, Vorschau und Hashdrift bei Änderung,
Hinzufügen/Löschen sowie Symlinkablehnung ab. Ergebnis der abschließenden
Ausführung: 18 Tests PASS; beide --check PASS; git diff --check PASS.
Negativprobe: README temporär verändert, STALE erkannt, Originalbytes restauriert.
Gemessene Codepakete: Route/Tests 9995 Zeichen und 203 +/- Zeilen;
Dateistand/Tests 5317 Zeichen und 118 Zeilen, jeweils zwei Dateien.
Zeichenmessung enthält Zeilenumbrüche und ist damit konservativ. Ein erneuter Generatorlauf
muss byteidentische Ansichten ergeben. Eine absichtlich veränderte Quelldatei
muss `project_state.py --check` mit STALE scheitern lassen.

## Umfang, Ausnahme und Rückweg

Aktueller Nutzerauftrag autorisiert die Übernahme der Entwicklungsgrundbasis.
Keine automatische G-1-/G0-Abnahme. Historische reine Planungsgrenzen werden
für die hier konkret beauftragten Entwicklungswerkzeuge erweitert.
EX-DOC-01: zusammenhängende Textrevision und generierte Dateisichten werden
als dokumentierte Dokumentations-/Generierungsausnahme behandelt.
Codepatches separat: Routenlogik/Tests und Dateistandslogik/Tests, jeweils
Kontrolliert, maximal 12000 Zeichen/250 +/- Zeilen/zwei Dateien.
Integration: Route, Blueprint, Workflow und README, separat gemessen.
Der Gesamtauftrag überschreitet ein einzelnes Patchbudget und wird nicht als
Micro-Patch bezeichnet. Dateihashes sichern Inhalte, nicht parallel sichere Writes.

Rückweg: ausschließlich die eigenen Änderungen gegen Ausgangscommit prüfen
und gezielt zurücknehmen; neu angelegte Artefakte nur nach Eigentumsprüfung
entfernen. Keine fremden Änderungen mit pauschalem Reset übergehen.
Es wurden keine Nutzdaten migriert, keine Anwendung veröffentlicht und kein
Merge vorgenommen. Lokale Änderungen sind bereit zur Repositoryprüfung.
